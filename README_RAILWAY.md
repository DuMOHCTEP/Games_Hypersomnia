# Развертывание Hypersomnia на Railway.app

## Обзор

Этот гид поможет развернуть игровой сервер Hypersomnia на платформе Railway как микросервис. Railway автоматически обрабатывает масштабирование, мониторинг и развертывание.

## Быстрый старт

### 1. Подготовка репозитория

Убедитесь что в корне проекта присутствуют следующие файлы:
- `Dockerfile.railway` - оптимизированный Dockerfile для Railway
- `railway.toml` - конфигурация Railway
- `railway.json` - дополнительные настройки (опционально)
- `start-railway.sh` - стартовый скрипт
- `railway-server-config.json` - базовая конфигурация сервера

### 2. Развертывание на Railway

#### Вариант A: Через GitHub интеграцию
1. Заходим на [Railway.app](https://railway.app)
2. Нажимаем "Deploy from GitHub repo"
3. Выбираем репозиторий с Hypersomnia
4. Railway автоматически определит конфигурацию из `railway.toml`

#### Вариант B: Через Railway CLI
```bash
# Установка Railway CLI
npm install -g @railway/cli

# Логин в Railway
railway login

# Инициализация проекта
railway init

# Развертывание
railway up
```

### 3. Настройка переменных окружения

В панели Railway установите следующие переменные:

#### Обязательные переменные:
```bash
SERVER_NAME="[Railway] Hypersomnia Server"
RCON_PASSWORD="ваш_безопасный_пароль"
MAX_PLAYERS="20"
```

#### Опциональные переменные:
```bash
DEFAULT_ARENA="de_cyberaqua"          # Стартовая карта
SYNC_ARENAS="true"                    # Загрузка карт сообщества
DISCORD_WEBHOOK_URL=""                # Webhook для уведомлений Discord
CASUAL_SERVERS="1"                    # Количество казуальных серверов
RANKED_SERVERS="0"                    # Количество рейтинговых серверов
WEBRTC_PORT="9000"                    # Порт для веб-клиентов
DAILY_AUTOUPDATE="false"              # Автообновления (лучше отключить на Railway)
```

## Технические детали

### Порты

Railway автоматически назначает основной порт через переменную `$PORT`. Дополнительно используются:

- **8412/UDP** - Нативные игровые клиенты
- **9000/UDP** - Веб клиенты (WebRTC)

### Архитектура

```
Internet → Railway Load Balancer → Docker Container → Hypersomnia Server
                                                    ├── UDP:8412 (Native clients)
                                                    └── UDP:9000 (Web clients)
```

### Особенности Railway

1. **Автоматическое масштабирование**: Railway может автоматически масштабировать сервер при нагрузке
2. **Мониторинг**: Встроенные метрики CPU, памяти и сети
3. **Логирование**: Централизованные логи доступны в веб-панели
4. **Домены**: Автоматически выделяемые HTTPS домены

## Администрирование

### Доступ к RCON панели

1. Запустите игровой клиент Hypersomnia
2. В настройках (`Settings → Client`) установите ваш RCON пароль
3. Подключитесь к серверу
4. Нажмите `ESC` для доступа к админ панели

### Мониторинг сервера

В Railway панели доступны:
- Метрики производительности
- Логи в реальном времени  
- Статистика сетевой активности
- История развертываний

### Обновление сервера

Railway автоматически пересобирает контейнер при:
- Пуше в основную ветку репозитория
- Изменении переменных окружения
- Ручном запуске пересборки

## Настройка Discord интеграции

Для получения уведомлений о подключениях игроков и результатах матчей:

1. Создайте Webhook в вашем Discord сервере:
   - Настройки сервера → Интеграции → Webhooks → Новый Webhook
2. Скопируйте URL webhook
3. В Railway панели установите переменную `DISCORD_WEBHOOK_URL`

Пример уведомлений:
- Подключение/отключение игроков
- Результаты матчей с MVP
- Начало дуэлей 1v1

## Карты и контент

Сервер может автоматически загружать карты сообщества:
- Установите `SYNC_ARENAS="true"` 
- При первом запуске скачается ~100MB карт
- Игроки будут автоматически скачивать карты при подключении

Поддерживаемые карты по умолчанию:
- `de_cyberaqua` - основная карта с подводной тематикой
- `de_silo` - индустриальная карта
- `de_metro` - карта метро
- `de_duel_practice` - карта для дуэлей
- `de_facing_worlds` - классическая карта

## Производительность

### Рекомендуемые ресурсы Railway:
- **CPU**: 1-2 vCPU (зависит от количества игроков)
- **RAM**: 512MB - 1GB
- **Сеть**: До 100 Mbit/s (UDP трафик)

### Оптимизация:
- Сервер использует детерминистическую симуляцию
- Сетевой трафик ~40 kbit/s для 2 игроков при 60 Hz tickrate
- Оптимальный tickrate автоматически регулируется

## Диагностика

### Проверка статуса сервера:
```bash
railway logs                    # Просмотр логов
railway status                  # Статус развертывания
railway variables               # Текущие переменные окружения
```

### Типичные проблемы:

1. **Сервер не запускается**:
   - Проверьте логи Railway
   - Убедитесь что установлены обязательные переменные
   - Проверьте корректность `RCON_PASSWORD`

2. **Игроки не могут подключиться**:
   - Убедитесь что порты UDP открыты
   - Проверьте что сервер слушает правильные порты

3. **Высокое потребление памяти**:
   - Уменьшите `MAX_PLAYERS`
   - Отключите `SYNC_ARENAS` если карты не нужны

## Безопасность

- Используйте сложный `RCON_PASSWORD`
- Discord Webhook URL держите в секрете
- Регулярно проверяйте логи на подозрительную активность
- Railway автоматически обеспечивает HTTPS для веб-трафика
