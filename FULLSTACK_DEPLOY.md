# 🌐🎮 Полная связка Hypersomnia на Railway

## 🎯 Обзор

Теперь ваш Railway проект включает **полную связку**:
- 🌐 **Веб-клиент** (ваш собственный домен)
- 🎮 **Игровой сервер** (UDP порты)
- 🔧 **Health Check** (HTTP для Railway)
- 🌍 **Nginx** (статические файлы)

### 🏗️ Архитектура:

```
┌─────────────────────────────────────────────┐
│                Railway Container             │
│                                             │
│  🌐 Nginx (port 80)                        │
│  ├── Статичные файлы веб-клиента           │
│  ├── WASM + JS + HTML                      │
│  └── CORS + безопасность                   │
│                                             │
│  🎮 Hypersomnia Server (UDP 8412/9000)     │
│  ├── Игровой движок                        │
│  ├── WebRTC для веб-клиентов               │
│  └── Нативные клиенты                      │
│                                             │
│  🔧 Health Check (Railway PORT)            │
│  └── HTTP мониторинг для Railway           │
└─────────────────────────────────────────────┘
```

## 🚀 Развертывание

### 1. Переименовать Railway конфигурацию
```bash
cd /var/www/neonpsh.ru/games/hypersomnia

# Переименовываем railway.toml в railway-server-only.toml
mv railway.toml railway-server-only.toml

# Используем fullstack конфигурацию 
mv railway-fullstack.toml railway.toml
```

### 2. Деплой полной связки
```bash
# Автоматический деплой
./simple-deploy.sh

# Или вручную
git add -A
git commit -m "deploy: переход на fullstack архитектуру"
git push origin production
```

### 3. Переменные окружения в Railway
```bash
SERVER_NAME = "[Portal] Ваш Игровой Портал"
RCON_PASSWORD = "ваш_админ_пароль"
MAX_PLAYERS = "20"
PORTAL_NAME = "Название Вашего Портала"
```

## 🌐 Доступ к игре

### Ваш собственный веб-клиент:
```
https://your-railway-domain.railway.app/
```

**Игроки заходят на ВАШ сайт** и играют через ваш веб-клиент!

### Нативные клиенты подключаются к:
```
your-railway-domain.railway.app:8412
```

## ✅ Что получаете:

### 🎮 Полностью автономный игровой портал:
- **Свой домен** для веб-клиента
- **Независимость** от hypersomnia.io
- **Полный контроль** над клиентом и сервером  
- **Кастомизация** интерфейса и брендинга

### 🔧 Техническая архитектура:
- **Multi-stage Docker build** с Emscripten
- **Nginx** для обслуживания веб-клиента
- **WebAssembly** игровой движок в браузере
- **WebRTC** подключение к локальному серверу
- **HTTP Health Check** для Railway мониторинга

### 📊 Мониторинг:
- **Все процессы** отслеживаются в реальном времени
- **Автоматический перезапуск** при сбоях
- **Railway метрики** CPU, памяти, сети
- **Детальные логи** всех компонентов

## 🎨 Кастомизация

### Брендинг веб-клиента:
1. **Название окна**: изменить в `portal-web-config.json`
2. **Иконка**: заменить `app.ico` 
3. **Стили**: настроить `common.css`
4. **Логотип**: заменить в HTML шаблоне

### Настройки игры:
1. **Ник по умолчанию**: в `portal-web-config.json`
2. **Клан игроков**: `[Portal]` или ваш
3. **Стартовое разрешение**: 1200x700 
4. **FPS лимит**: 60 для веб-клиента

## 🐛 Диагностика

### Проверка статуса всех сервисов:
```bash
railway logs --follow
```

Должно показывать:
```
✅ Health check server запущен с PID: 123
✅ Nginx запущен с PID: 456  
✅ Игровой сервер запущен с PID: 789
🚀 ИГРОВОЙ ПОРТАЛ ГОТОВ К РАБОТЕ!
```

### Тестирование веб-клиента:
1. Откройте https://your-railway-domain.railway.app
2. Должен загрузиться веб-клиент Hypersomnia
3. В меню выберите "Connect to Server" 
4. Должен подключиться к локальному серверу автоматически

### Тестирование нативного клиента:
1. Скачайте игру с hypersomnia.xyz
2. Connect to Server → введите ваш Railway домен:8412
3. Должен подключиться к вашему серверу

## 🔒 Безопасность

### CORS настройки:
- **Cross-Origin-Embedder-Policy**: require-corp
- **Cross-Origin-Opener-Policy**: same-origin
- **Content-Security-Policy**: строгие правила

### Nginx безопасность:
- **X-Frame-Options**: защита от фреймов
- **X-XSS-Protection**: защита от XSS
- **X-Content-Type-Options**: защита MIME
- **Gzip сжатие**: для ускорения загрузки
